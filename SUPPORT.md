# Support

KeePassKeyWin is pre-1.0 community software maintained by volunteers. There is no
commercial support, SLA, or guaranteed response time.

## Where to get help

- **Documentation** — start with [`docs/`](docs/) and the [README](README.md).
  [`docs/WINDOWS_VALIDATION.md`](docs/WINDOWS_VALIDATION.md) has a step-by-step
  runbook for first-time setup.
- **GitHub Discussions** — preferred venue for questions, design input, and
  usage help. <https://github.com/MarcoLodini/KeePassKeyWin/discussions>
- **Bug reports** — open an issue using the bug report template.
  <https://github.com/MarcoLodini/KeePassKeyWin/issues/new/choose>
- **Security vulnerabilities** — follow the [security policy](SECURITY.md).
  Do not open a public issue.

## Supported versions

Only the latest commit on `master` is supported. Tagged releases will be
announced once v1.0 ships. See [`SECURITY.md`](SECURITY.md) for details.
